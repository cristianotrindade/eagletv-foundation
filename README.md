# EagleTV Foundation

Crie do ZERO um novo projeto chamado EAGLETV.

O objetivo desta primeira etapa é construir SOMENTE a fundação visual, estrutural e técnica do novo site EagleTV.

Não criar ainda páginas adicionais, área de cliente, sistema de login, pagamentos ou funcionalidades complexas.

Primeiro quero validar o DESIGN e a ESTRUTURA.

==================================================
IDENTIDADE DO EAGLETV

Nome da marca:

EAGLETV

Conceito:

Uma plataforma moderna de entretenimento e streaming, com identidade visual inspirada na força, velocidade e visão de uma águia.

A águia deve transmitir:

força

tecnologia

liberdade

velocidade

precisão

qualidade

A identidade deve ser moderna e premium.

Evitar aparência de site genérico criado por IA.

==================================================
PALETA VISUAL

Fundo principal:
preto / quase preto

Cor principal:
azul neon

Cor secundária:
azul elétrico

Texto:
branco

Texto secundário:
cinza claro

A paleta deve transmitir tecnologia e entretenimento.

Não utilizar muitas cores diferentes.

Criar variáveis CSS para as cores para que possam ser alteradas posteriormente em um único lugar.

HERO

Apresentar a marca EagleTV imediatamente.
